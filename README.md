# 思路 · Project Mind Map

把问题、证据与下一步，连成一张图。

这个仓库用于提供 Windows 安装包和自动更新文件。

## 下载

前往 [最新版本](https://github.com/sbdyl/Project-mind-map-releases/releases/latest)，下载 `setup.exe` 安装版或 `portable.exe` 免安装版。支持 Windows 10 / 11 x64。

已有旧版的用户请先关闭程序，再运行新版 setup 覆盖安装；已有项目保留。v0.2.1 起，安装版会自动检查和下载更新，下载后点击“保存并重启更新”。也可以通过“帮助 → 检查更新”手动检查。免安装版需要手动下载新版。

## 使用

- 双击画布空白处新建节点，点击节点编辑 Markdown 笔记。
- 从节点边缘的 + 拖出连线；Shift 点选两个节点查看连接路径。
- 左侧菜单切换工作空间，“打开工作空间”定位文件夹。
- 工作空间列表右侧 × 可删除对应 JSON 与索引记录，确认时输入“删除”；图片、文件夹及其他文件保留。
- 数据自动保存在本机；顶部出现“已保存到本地”后可关闭。

安装包尚未进行代码签名，Windows 可能显示未知发布者。发布页同时提供 SHA256SUMS.txt，便于核对下载文件。
